# 技术历史

本目录保存经过整理的排错经验、设计取舍和审计证据，帮助贡献者理解当前实现的来源和历史误区。个人沟通、本机位置和临时执行流水不在此公开。模板的多数深层案例沉淀在源工程 [STS2-Navia](https://github.com/SlayTheCircle/STS2-Navia) 的技术历史中；本目录从模板自身的沉淀开始积累。

| 文档 | 范围 |
|---|---|
| [运行时与管线案例](incidents.md) | 资源、加载、审计与确定性产物的事故记录 |
| [方案取舍](decisions.md) | 模板形态、分发布局与回流机制的已采纳决策 |
| [设计原案与对照](design/README.md) | 设计输入（含花名册格式）与实现差异记录 |

## 如何使用历史证据

历史行号、模型数量、素材状态和建议可能已变化。报告中的 CONFIRMED 表示当时复核成立，不表示当前仍有缺陷；DISMISSED 的理由也保留为参考。未逐项维护修复状态时，不能将报告视为当前缺陷清单或完整验收结论。

案例记录现象、根因、修复和防止再次发生的约束。新的历史记录注明对应游戏／依赖版本与证据类型；将稳定结论同步到所属现行手册，保留可理解的演变背景。
