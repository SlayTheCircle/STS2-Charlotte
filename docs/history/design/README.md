# 设计输入与技术历史

本目录保存设计过程性记录：设计输入整理、设计实现差异日志、已采纳方案评估。模板阶段只携带花名册格式与对照机制；各衍生 Mod 在此累积自己的原案。

当前确定性设计体系见[设计资料](../../design/README.md)：现行卡表由脚本从源码与本地化生成；数量、验收与限制由 [STATUS](../../../STATUS.md) 维护。

| 文档 | 性质 |
|---|---|
| [卡牌花名册](card-roster.txt) | 设计卡牌清单（类型／稀有度／费用／效果）；花名册审计的默认输入，须与实现类数一致 |
| 设计与实现对照（衍生仓自建） | 差异日志：已确认调整、定夺与勘误；随设计变更持续更新 |

花名册格式：每行一条 `名（攻击|技能|能力）...`，名称须与本地化中文标题一致；审计核对花名册↔本地化标题↔实现类计数三方一致。token／新增／延后内容经审计脚本的集合声明登记。

原案保留设计者提供的数值和叙事，不静默替换；确认设计变更时更新对照说明、对应实现和运行文本。母版存放于组织私有美术仓（限定授权）；许可范围见 [LICENSING](../../../LICENSING.md)。
